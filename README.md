# Flipkart Seller Manager

Personal Flipkart seller operations system.

## Stack

- Next.js
- Vercel
- Supabase Postgres + Auth
- Flipkart Self Access API

## Current status

The Supabase project and Vercel project are connected. The app currently performs a server-side Supabase connectivity check.

## Security

Flipkart credentials and Supabase service-role credentials must remain server-side. Never prefix secrets with NEXT_PUBLIC_.
